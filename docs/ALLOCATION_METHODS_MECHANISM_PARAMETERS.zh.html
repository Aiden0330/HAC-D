可靠性指标分配方法与 19 项故障管理机制的参数分配

分配 = 把系统级目标（故障率 λ*、可靠度 R*、可用率 A*、goodput G*）自顶向下拆成每个部件类、每个恢复阶段、每项机制参数的需求，再自底向上预测、迭代。公式与 HAC-D 的实现一致（packages/core/src/allocation、scenario/analysis.ts、mechanisms/）。口径规则：同一事件类、同一分母、同一层级；中断、亚健康、静默错误三类事件的量不能相加，只能各自进入窗口账本后再合成。

1. 经典分配方法（串联系统，故障率预算 λ*，m 个子系统）

记号：λᵢ⁰ 当前合计率（单元率 × 数量 nᵢ）；λᵢ* 分配率；改进倍数 kᵢ = λᵢ⁰ / λᵢ*（< 1 表示可以恶化）。标为"固定"的类先按当前值从 λ* 中扣除，再分配其余。单元级验收值 = λᵢ* / nᵢ（HAC-D 以每 10⁶ 单元·小时给出）；分配率低于参数库已知最优值时标记 tighter-than-best-known。

2. AI 训练作业：从 goodput 目标到中断预算（HAC-D 可用性分配页，自上而下）

① 口径链：正确交付 → 有效 → 中断项

G_eff* = G_d* / f，f = 正确交付 ÷ 有效（静默错误的交付系数）；G_head* = G_eff* / φ，φ = (1 − P_blocked) φ_job (1 − ℓ_local)(1 − o)（备件耗尽、亚健康降速、弹性域损失、机制开销）。中断预算只对 G_head* 做。

② 仅靠硬件可达性 → 必需杠杆

所有故障率 → 0、静默策略不变时的 G_d^max；若 G_d^max < G_d*，硬件再好也不够：报告硬件不变时的最小即时检出率 q* = min{q : G_d(q) ≥ G_d*} 与检出率不变时的最长兜底发现时延 D* = max{D : G_d(D) ≥ G_d*}（二分）；下方预算在 q* 下计算，q = 1 仍不够则按 q = 1 计算并说明中断侧还须补足多少。

③ 窗口账本损失预算（九个账本项）

L* = 1 − G_d*，allowedₖ = L*·wₖ，k ∈ {停机、CKPT 保存、回滚、亚健康降速、弹性域损失、备件耗尽、机制开销、静默回滚、期末判废}；权重按当前账本比例（默认）、在有损失的项上均分、或自定义（ReMAP 参考权重 停机/保存/回滚/判废/降速/域损失 = 25/20/35/10/5/5 %）。超出ₖ = 当前ₖ − allowedₖ，先攻超出最大的项；拆分是记账目标，不证明各项可独立达到。

④ 中断预算（Young 间隔一阶式，与方法无关）

M = 3600 / (N λ_GPU) s，τ_Y = √(2δM)，L = √(2δ/M) + R/M，L* = 1 − G_head*。保持 R 压缩 λ：解 √(2δ)·s + R·s² = L*（s = M^{−1/2}）得 M* = 1/s²，λ_job* = 3600/M*；保持 λ 压缩 R：R* = M (L* − √(2δ/M))；均衡：L_r = ρL*，L_c = (1−ρ)L*，M_bal = 2δ/L_c²，R_bal = L_r·M_bal（ρ 重启项占比，默认 0.5）。有效条件 (τ+δ)/M ≤ 0.1 且 R/M ≤ 0.1，否则标注并改用完整 Daly 模型。

⑤ 拆到部件类与恢复阶段

λ_job* 按第 1 节方法拆到部件类（每单元允许率 = 验收 FIT）。恢复阶段：budgetᵢ = floorᵢ + (wᵢ − floorᵢ) / Σⱼ(wⱼ − floorⱼ) · (R* − Σ floor)，wᵢ 默认当前阶段时间，检测 / 定位下限 5 s；阶段 = 检测、自动尝试、人工份额，或流水线各段（检测、定位、重调度、加载、重算除外）。

⑥ 两条筛选律

无故障上界：G ≤ (⌊S/L⌋τ + min(S mod L, τ)) / S ≤ τ/(τ+δ)，L = τ+δ，S 窗口秒数；目标高于最佳机制组合的上界即"已证明不可达"。规模律：按将运行的最大 N 分配——检测与恢复项 ∝ N，checkpoint 项 ∝ √N（Young 间隔），静默污染次数 ∝ N。

读表口诀：改进倍数 ×1.6 = 该类中断率须降到今天的 1/1.6；×0.98 = 可以恶化 2 %，这时故障率表与阶段表是验收限值而非改进任务。分配页只在"各类之间怎么拆"上随方法不同；损失预算、预算卡片与阶段预算与方法无关。

3. 选组合、降额与算例

选机制组合与降额（机制页"按目标规划"）

目标值 = 最低工作量之和（表中分值，可编辑）的可行组合，名义参数与降额参数都须 ≥ 目标；"必要机制" = 出现在所有可行组合中的机制；Pareto 前沿列出工作量 – 价值的备选。默认降额 DERATE_DEFAULT：覆盖率 −5 pt，成功率 / 召回 / 精度 −8 pt，时间 ×1.5，削减比例 ×0.5，开销 ×1.5；计算间隔 τ 与域数是设计量，不降额。替代关系（重执行、热替换、弹性、进程重调度：收益递减，按 mechanisms.order 依次尝试）与互补关系（D-SDC + R-SDC；D-SLOW + H-SWEEP）决定组合时的先后。

算例（用户手册 §7.5–7.7，页面可复现）

B · 同目录、95 %：q = 1 也只到 94.69 % → 预算按 q = 1：中断率再降 6 %（ARINC 每类 ×1.06）或恢复加快 13 %（阶段 13 s / 2.7 min / 64 s）。

C · 三类基线、5 万卡、90 %：q* = 71.54 %；套用 95 % 检出后正确交付 95.43 %，中断侧四倍余量（×0.25），表格成为硬件与恢复可恶化的限度。

4. 19 项故障管理机制：参数怎么分配

流程（分配页 → 机制页 → 分配页 → 校核），每一步对应页面上的一个控件；表中"分配规则"把 §2 的账本项允许值反推成机制参数的设定值。

① 定口径分配页：目标口径 = 正确有效产出，G*，窗口天数，最大 N
② 必需杠杆静默错误卡片：仅靠硬件可达？不可达 → q* 与 D* 是硬需求
③ 先攻哪项损失预算卡片：按"超出"排序；每项列出驱动它的机制杠杆
④ 排序机制页"归因"：Shapley 份额（公平排序）、单项收益、末位加入收益
⑤ 选组合机制页"按目标规划"：最低工作量之和的可行组合，名义与降额参数都须达标；必要机制；Pareto 前沿
⑥ 定参数"应用到方案"后回到分配页：剩余中断预算拆到部件类（§1）与恢复阶段（§2⑤），按下表反推各参数
⑦ 校核规划器校核或蒙特卡洛页（"全部页面"模式）：P(窗口 ≥ 目标) ≥ 置信度（默认 90 %），Wilson 判定 supported / uncertain / below
⑧ 闭环实测后用 hacd rate（Garwood 区间）回写故障率、阶段时间、检出率，重跑
